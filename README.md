# PostgreSQL Data Extraction Pipeline

An end-to-end Python pipeline designed to extract data from a PostgreSQL database, execute SQL queries, and export the processed results to a structured CSV file.

## 📌 Project Overview

This project sets up an automated data extraction workflow for Week 1 of my data engineering practice. It connects to a PostgreSQL database, runs targeted SQL queries, and exports the retrieved dataset into `extracted_data.csv` for downstream analysis or reporting.
